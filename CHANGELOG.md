# Changelog

## 1.0 (versionCode 19)

- Quick button: tapping one with no action set opens its setup. It moves when the music bar changes height.
- Music: one bar for all players, swipe sideways to switch, swipe away to hide. Tapping it opens the app.
  New setting to use an app's own widget instead of the launcher's controls.
- Folder pop-ups open at the top, no longer redraw while you scroll, and only redraw when something changed.

Earlier builds (versionCode 1–18) were not published.
