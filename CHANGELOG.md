# Changelog

## 1.1 (versionCode 20)

- Media apps' own widgets now show on home automatically while the app plays or is paused. The first time an
  app with widgets plays, you are asked once whether to use its widget. Settings → Media app widgets lists the
  media apps found (any that have played, plus apps in a folder named Media, Music, Audio or Podcast).
- Swipe a media widget up or down to send it away until that app plays again.
- The app list shrinks (to half size at most) so every app fits with no paging while music controls or a media
  widget are on home. Can be turned off.
- Quick button: new built-in icons (target, dot, plus, arrow up, search, grid, lines, ring), now the default.

## 1.0 (versionCode 19)

- Quick button: tapping one with no action set opens its setup. It moves when the music bar changes height.
- Music: one bar for all players, swipe sideways to switch, swipe away to hide. Tapping it opens the app.
  New setting to use an app's own widget instead of the launcher's controls.
- Folder pop-ups open at the top, no longer redraw while you scroll, and only redraw when something changed.

Earlier builds (versionCode 1–18) were not published.
